Three symptoms. Three causal fixes.

The work followed the failure from host environment selection through ACP events to the rendered transcript. Each visible symptom is tied to a mechanism and a fresh proof.

Reported symptom

ls attempted on Windows

The agent could infer a POSIX command while the product was actually running on Windows, producing avoidable failures and misleading recovery.

→
Causal repair

Bind one explicit host capability

Forge resolves an absolute cmd.exe once, carries the same frozen profile into ACP, prefers structured reads, and conservatively preflights commands before approval or process creation.

→
Observed proof 47 / 47

Real-Windows seam tests. An absent exact ls becomes Not run before permission; compatible commands still use approval and workspace cwd.

Reported symptom

The tool list could not be scrolled

Long, dynamically settling activity competed with the outer transcript for height and scroll ownership. At zoom, the rail could collapse or push controls out of view.

→
Causal repair

Give the activity body its own viewport

The group is bounded to the transcript, its body owns native scrolling, and first-visible-row anchoring preserves position during updates. Header, composer, and topbar remain stable.

→
Observed proof 45 rows

Wheel, native thumb, Page Up/Down, Home, and End reach every row at 100% and 200% in Chromium and packaged WebView2.

Reported symptom

Rows disappeared or left visual debris

Legacy event ambiguity, result-first ordering, flex shrink, and paint containment could erase settled evidence, duplicate it, or leave bordered fragments behind.

→
Causal repair

Keep one truthful activity record

A strict current tool_run union preserves first-sight order and terminal facts. Result-first updates fill only missing detail. Groups remain open until the operator collapses them; disconnect freezes known evidence.

→
Observed proof 0 ghosts

One group, two top-level decision chips, no duplicates, no blank rows, and truthful 1 failed · 1 not run summaries across settle and scroll-away/back.

Technical ledger

What changed under the surface.

Open a section for the implementation detail. These are grouped by responsibility rather than by commit because the work remains intentionally uncommitted.

Host and shell capability
  • Resolved one immutable execution profile from explicit host inputs.
  • Advertised the same absolute executable later invoked with /d /s /c.
  • Removed ambient platform, ComSpec, and SystemRoot fallbacks.
  • Kept the effective environment private and frozen.
Preflight and process safety
  • Added a conservative cmd-aware scanner for segments, quoting, caret escapes, and assignment prefixes.
  • Uses controlled Path/PATHEXT lookup and rejects only proven absence.
  • Starts approved commands in workspace cwd with explicit spawn semantics.
  • Preserves the existing permission policy for compatible commands.
Truthful ACP event contract
  • Introduced the closed current-version tool_run event union.
  • Separated Not run from executed failure in UI, recovery context, and logs.
  • Rejected malformed current events and legacy ambiguity.
  • Protected terminal facts during result-first detail enrichment.
Persistent activity presentation
  • Anchored one activity group at the run’s first tool sight.
  • Kept permission and diff chips outside the group at their own rail positions.
  • Made disclosure state operator-owned through updates and settlement.
  • Rendered supplied terminal error/reason detail and an explicit offline qualifier.
Scroll, focus, and paint
  • Bounded the activity group to the transcript and assigned scroll ownership to its body.
  • Preserved first-visible identity and pixel offset across row updates.
  • Prevented flex collapse, subpixel header clipping, and zoom-driven topbar loss.
  • Verified Tab entry/exit, stable focus, visible focus, and native scrollbar dragging.
Test and observation seams
  • Added a deterministic test-only ACP entry outside production build inputs.
  • Drove real host HTTP/WebSocket → ACP JSON-RPC → GrokAcpServer boundaries.
  • Expanded browser journeys for settle, scroll, decisions, disconnect, stale tails, and zero-tool runs.
  • Restored real packaged resources and cleared isolated listeners after observation.
