One product decision · locked 25 Aug 2026

Forge can be Grok’s desktop — or a thinner cousin.

Locked · Option A   Forge is the GUI. Grok’s real agent is the Code brain. Not a terminal skin.

Same prompt. Same repo. Same day. The terminal Grok app finished the job. Forge Code did not. This page is the two ways to fix that, in pictures, without jargon.

Option A · recommended

Plug into Grok’s real agent

Forge stays the window, the rules, and the taste. Grok’s own coding agent does the thinking and tools — the same one the terminal uses.

  • Skills like /spire-tech just work.
  • Thinking, tools, and long jobs match the terminal.
  • Later, Codex or Claude can plug in the same way.
Option B

Keep writing our own Grok

Forge keeps its private mini-Grok (eight tools, our rules). We rebuild slash commands, skills, thinking, and long runs ourselves.

  • We own every rule and the installer stays simple.
  • We will always lag the terminal on “real Grok Code.”
  • Codex/Claude each need a whole new mini-agent.
In one sentence. The product we said we are building is a desktop that can host any coding agent. Grok is the first guest — not the whole house. Option A is that sentence. Option B is “we said that, then we kept building a private Grok.”

Read this twice

There is a good A and a bad A

Good A

Forge is the house. Agents are guests.

The window, the ask-before-edit rules, File changes, Chat homes — those stay ours. Grok’s full agent is invited in for Code. Later we invite Codex or Claude. If Grok isn’t installed, our mini-Grok still answers the door.

Bad A

Forge becomes a skin on the terminal

Rip out our agent, skip our ask-before-edit rules, copy the terminal’s look. Fast TUI parity. Then we are Grok-only, and the “any agent desktop” story is dead.

Do not pick bad A. The rest of this page means good A whenever it says A.

Will we get stuck?

Four different kinds of lock-in

“Lock-in” is not one monster. These are four smaller ones. Good A unlocks the first. Bad A and B lock the others.

1 · language

How they talk

ACP is the shared language. If Forge learns the public language, guests can come. If we only speak our private slang, only our mini-Grok can.

2 · vendor

Whose brain

Bad A: stuck on Grok forever. Good A: stuck on “anyone who speaks ACP” — the bet we already made. B: stuck on our Grok-shaped toolkit; Codex can’t reuse it.

3 · trust rules

Ask before edit

This is our moat versus the terminal. A must map Grok’s “may I run this?” into our dock. B already has it. Don’t trade this away for pretty thinking.

4 · shipping

What’s in the box

A: we depend on (or bundle) Grok’s program. Updates follow them. B: one box we already know. Simpler for a first-time PC. Thinner Grok inside.

The reversible door. Starting Grok’s agent is one line in the host. Keep our mini-Grok as backup. B gets expensive to leave only if we keep inventing private messages the rest of the world doesn’t send. If we might ever do A, stop deepening that private slang now.

Tomorrow and later

How each choice changes the next years

If we pick A, day-to-day building becomes…

  • Less “invent a coding agent,” more “draw the stream and keep our rules.”
  • A new provider is “invite a new guest,” not “write a new brain.”
  • /spire-tech and friends start working when skills appear in the box.
  • Tests must watch a real (or recorded) vendor agent — not only our fake one.

If we pick B, day-to-day building becomes…

  • Every terminal screenshot is a Forge ticket: slash, skills, thought, long runs.
  • “Skills and hooks” becomes a long project, not a menu on Grok’s skills.
  • Codex/Claude stay on the later pile because each is a product.
  • We keep shipping beautiful panels on an agent people won’t use for hard jobs.

Non-negotiables

What we keep on either path

  • Ask before dangerous work — Review, Trusted, Bypass. The dock stays.
  • File changes, Verify, git review, Plan — first-class panels, not buried tool rows.
  • Chat names and pinned files — everyday Chat is a product, not a leftover.
  • Stay in the folder — no sneaking out. Shell is honestly not a sandbox after you allow it.
  • Thinking is not the answer — the reply is the reply. Thought can collapse.
  • Voidglass — cyan on night glass. We do not paste the terminal into a webview.

If we had to ship a sentence

Recommendation

Pick good A · with a seatbelt
  1. Teach Forge the public language — thought, tools, and words as separate live streams — even while our mini-Grok still runs.
  2. Invite Grok’s real agent for Code when it is installed. Keep our ask-before-edit dock in front. Never “always allow” as the only mode.
  3. Keep our mini-Grok as backup — no Grok program, Chat, or Forge-only tricks (PDF text, Trusted catalog).
  4. Do not grow the mini-Grok into a fake terminal — no home-grown skill engine, nested agents, or extra-high harness. That is B in disguise.

Pick B only if we are willing to say out loud: “Forge Code will stay a thinner Grok. The terminal remains the real Grok Code.” That can be an honest Chat-first product. It is not “the GUI should feel as good as the terminal or better.”

How to answer

A — good A, seatbelt, Grok agent for Code.
B — stay on our mini-Grok and catch up ourselves.
