## 1. Why this exists

Named journeys (Chat C*, Code A*/D*/E*/F*) proved the engine flip and a daily-job floor. They also taught the wrong lesson: **green twice + Q clean = done**.

The product you want is the app you open first, all day, instead of Claude Code, Codex, Cursor, Claude.ai, or ChatGPT. That is not a finite table. It is a loop of using Forge, noticing what is worse, and making a **measured** change.

Exceed those tools. Do not copy their layout or their marketplace.

## 2. Goal kind

`code-change` with **live dogfood** of the running app. Whole-app. Chat and Code both in play. Shared chrome (composer, docks, Your turn, wait copy, export, hierarchy) is in scope on whichever tab you are using.

## 3. What “better” means (measure, don’t vibe)

A slice is only done if **one axis** moved in a way a stranger could check. Pick the axis that the elected defect actually lives on.

| Axis | Better looks like | Prove with |
|------|-------------------|------------|
| **Function** | A daily job completes (send, Review write, Plan accept then edit, test, git via shell, follow-up memory, export, stop/retry/copy) | Disk / tool output / JSON observables match the job |
| **Honesty** | Failures, identity, and “not run” are true; no hydrating lies; no fake catalogs | Shot + JSON; no Mini-Grok / Grok Code consolation; no dump markers |
| **Hierarchy** | You / Thought / Plan / File changes / tools / Answered / Your turn / composer don’t cover each other | Layout flags (`*Below*` true, `*CoveredBy*` false) + screenshot |
| **Voice** | Sentence-case; idle **Your turn**; wait **Waiting for model…**; Thought ≠ answer | Body text; no shouty uppercase instruction |
| **Interaction** | Docks settle; composer enables when it should; Deny/Retry/Revert/Pause/Stop do what they say | Click log + composer enabled + disk |
| **Density** | One turn scannable at 1440×900 without hunting | Screenshot at that size |
| **Motion / perf** | No max-update-depth; no black-crash; no jank on send | Console; `maxDepth: false` |
| **Desktop = web** | Same observables on Forge Dev | Banner `host :8788`; `:8810` down |

Taste without a hidden job (prettier with no clip, no lie, no blocked send) is still in scope **if** you can name the before/after (e.g. wait heading was uppercase, now it isn’t). Unnamed “make it nicer” is not a slice.

**Out (still refuse):** MCP marketplace, vendor skills catalog, computer use, Custom GPTs, voice, pixel-parity with Claude Code’s VS Code skin, re-enabling `grok agent stdio`.

## 4. The loop (this is the work)

Repeat until the operator says pause. Do not invent a Wave N table and then STOP when it is checked.

1. **Dogfood** — Drive Forge Dev (prefer Desktop CDP `:9222`, else DEV web `:5174`). Do a real job: a coding edit, a Chat rewrite, a Plan, a test run, an export, a follow-up. Invent the next job if the last one was easy.
2. **Observe** — Watch the live UI the way a user would. Read the shot, JSON, host log, composer enabled, docks, overlap flags, console.
3. **Evaluate** — Rank friction. Daily-blocked function and honesty beat clip. Clip and shout beat idle polish. Shared chrome that is wrong on **both** tabs beats a Code-only nit.
4. **Elect** — Exactly **one** defect. First FAIL in that ranking. Do not parallel-fix five things.
5. **Change** — Smallest fix. Chrome/behavior that can silently regress needs a test that **would have failed before**. Host/agent: prefer grok-acp/server truth over shell lies. If the same class will recur (post-terminal events, global dock queues, Answered-on-deny), close the class in the same slice.
6. **Prove** — Recapture the same job (png+json+txt). Quote the measured delta (e.g. `fileHeadBelowYou: false → true`; dock dismissed; wait copy `Waiting for model…`; test 1 pass). Whole-app: if you touched shared chrome, glance the other tab once.
7. **Log** — One broke/fix/re-check line in §9. Then go to 1. Do not wait for a Quality pass to invent the next job. Do not ask the operator whether to continue. Only the operator’s pause is STOP.

**Host rules:** one `:8788`. Occupied port: attach **or** kill the owned pid, never both. Desktop banner must be `host :8788`. Never start a second host. Scratch captures under temp only. Dedicated probe files under `docs/dogfood/acp-code/` — never rewrite `ACP-A3.md`. Follow-up execute (`FORGE_FOLLOWUP`) must click **Allow once** / **Accept**, not just wait for Your turn.
