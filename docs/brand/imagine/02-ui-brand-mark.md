## Brand context (required)

- **Product:** Forge. Wordmark “FORGE” sits **beside** this mark in the app chrome.  
- **Theme:** Aeon Continuum — same nucleus family as the desktop icon, but **simpler**.  
- This is a **logomark next to type**, not a desktop wallpaper jewel.  
- **Colors:** plasma `#7dffe8` → mind `#c4b5fd` on void `#03040a` (or transparent if available).

---

## Goal

Crisp mark at **24–40px** next to the FORGE wordmark. Prefer **logo/vector clarity** over photoreal glass chaos.

---

## Prompt (paste into Grok Imagine)

```
App UI brand logomark for Forge (product name is text next to this mark — do not draw any text).

Theme Aeon Continuum: far-future agent shell. Square 1:1. Designed for 24–32 pixel UI use next to a wordmark — must be ultra-crisp and simple.

Single minimal luminous Aeon nucleus: clean organic teardrop shape, almost vector/logo quality (not photoreal soap bubble, not heavy 3D render). Smooth soft gradient mint-cyan plasma #7dffe8 into violet mind #c4b5fd. One small white specular only. Pure black background #03040a (or transparent if available). Centered with padding.

No text, no letters, no “F”, no “FORGE”, no Grok branding, no anvil, no flame, no double shapes, no foggy glow that destroys the outline. Precision edges like a premium AI brand mark. Think icon-font clarity with liquid light color.
```
