# Imagine prompt — Desktop icon (Forge × Aeon Continuum)

**Use with:** `00-BRAND-BRIEF.md` (or brand capsule).  
**Aspect ratio:** **1:1 square**  
**Output:** highest resolution — **download as PNG** (not JPEG)  
**Background:** **transparent** (alpha), so the taskbar can show through  
**Save as:** `docs/brand/source/01-desktop-icon.png`  
**Installs to:** `apps/shell/src-tauri/icons/` (icon.png, 32, 128, icon.ico)

> JPEG is acceptable if PNG fails, but it cannot store transparency — light/checkerboard becomes a hard plate. Prefer PNG via Imagine’s Download / full-size save.

---

## Brand context (required)

- **Product:** Forge — desktop AI agent shell (Chat + Code, local tools).  
- **Theme:** Aeon Continuum — void field, plasma + mind light, living nucleus.  
- **Agent Grok** is inside the product; **do not** put Grok or any text on this icon.  
- **Colors:** void `#03040a`, plasma `#7dffe8`, mind `#c4b5fd`, optional white specular.

---

## Goal

Windows **taskbar / window / installer** icon. Must look premium at 512px and still be **recognizable at 16–32px**.

---

## Prompt (paste into Grok Imagine)

```
Desktop application icon for Forge, a premium desktop AI agent shell.

Brand theme Aeon Continuum: far-future light-field aesthetic. Square 1:1. **Transparent background** (alpha channel) — no black plate, no gray checkerboard baked into pixels. The mark alone floats on transparency for Windows taskbar.

Single centered brand mark: a luminous Aeon nucleus — bold organic teardrop-orb hybrid (one clear silhouette, not a messy blob). Liquid-glass material with smooth gradient from electric mint-cyan plasma #7dffe8 into soft violet mind #c4b5fd. One sharp specular highlight. Soft integrated glow on the mark only. High-end product icon (modern AI desktop app quality).

Mark fills most of the canvas (~90–96% of the box, minimal padding) so it matches other taskbar apps. Extremely crisp edges. High contrast so the shape reads when tiny.

No text, no letters, no monogram, no “F”, no “FORGE”, no “Grok”, no anvil, no hammer, no flame, no robot, no face, no UI chrome, no frame, no watermark, no floor shadow, no 3D pedestal.

Optimized for Windows taskbar: transparent bg, large fill, simple bold form first, glass beauty second. Export as PNG with alpha.
```

## Edit pass (if too soft / busy)

Same Forge Aeon Continuum desktop icon. Same composition and palette. Simplify silhouette. Reduce micro-detail and noise. Stronger edge contrast on pure black. Bolder form for 16px taskbar readability. Still no text.
