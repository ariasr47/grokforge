# Grok Imagine — Forge asset prompts

Self-contained prompt packs for **Forge** × **Aeon Continuum**.

## Start here

1. Read **`00-BRAND-BRIEF.md`** (product + theme + colors + do/don’t).  
2. Open the asset file you need (`01` … `07`).  
3. In Grok Imagine: paste brief (or brand capsule) + full asset file.  
4. Export masters into `docs/brand/source/` — **prefer PNG** (Download / full-size save). JPEG works; PNG keeps transparency for taskbar icons.  
5. Tell the eng agent the paths to install icons / UI mark.

### PNG vs JPEG

Grok Imagine is raster-only (no SVG). **PNG is downloadable** (button, new-tab save, right-click save). Some UI paths compress to **JPEG** and flatten alpha — use the download path for transparent icons.

## Rule of thumb

- **Always start with** [`00-BRAND-BRIEF.md`](./00-BRAND-BRIEF.md).  
- **Desktop + favicon:** bold silhouette > glass detail.  
- **UI mark:** reuse desktop PNG unless a flatter 26px variant is needed.  
- **Mark variants:** `01` teardrop nucleus · `08` alien forge — pick one primary for install.  
- **Mood hero:** full Aeon freedom.  
- **Never** put the word FORGE or Grok in the icon/mark renders.
