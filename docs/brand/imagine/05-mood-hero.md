# Imagine prompt — Mood / hero art (marketing & docs)

**Use with:** `00-BRAND-BRIEF.md`  
**Aspect ratio:** **16:9** (hero) or **3:2**  
**Output:** high-res  
**Save as:** `forge-aeon-mood-hero.png`  
**Use:** docs, brand page, presentations — **not** taskbar icon

---

## Brand context

Forge × Aeon Continuum full atmosphere. Here you may show **field, constellation, light** — not only the mark. Still avoid product-name lettering unless a separate controlled layout pass.

---

## Prompt

```
Cinematic brand hero image for Forge, an AI agent desktop shell, visual theme Aeon Continuum.

Wide composition. Deep void space #03040a with subtle constellation points of plasma #7dffe8 and mind-violet #c4b5fd light. A single living luminous nucleus (organic teardrop-orb of liquid glass, plasma-to-violet gradient) as the quiet focal point — not huge, not centered like a sticker; placed with elegant balance.

Atmosphere: far-future continuum, soft light-fields, calm intelligence, premium. Abstract — no people, no laptops, no code screenshots, no robots, no anvils.

No readable text, no logos of other companies, no watermark. Photoreal or hyperreal lighting OK; keep brand colors disciplined.
```

---

## Acceptance

- [ ] Feels like Aeon Continuum, not generic sci-fi  
- [ ] Plasma + mind + void palette  
- [ ] Usable as a wide banner  
- [ ] No garbled text
