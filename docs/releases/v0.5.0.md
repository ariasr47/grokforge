# Forge 0.5.0 — Plan, recipes, live follow, git review

Forge 0.5.0 completes the Code daily loop and makes Chat structured answers and primary buttons readable on the installed app.

## Highlights

- **Plan before write.** In Code, explore and propose without applying edits; accept the plan to continue under Review / Trusted / Bypass.
- **Repo recipes every Code turn.** Checked-in `AGENTS.md` or `CLAUDE.md` is included when present, with an honest empty or failed voucher when it is not.
- **Live turn stays on screen.** The latest tools stay in view; the next permission or diff sits in the sticky dock; “Your turn” waits until the run is idle.
- **Git review.** After a Code run, journaled `git status` / `diff` / `log` / `show` (and `gh pr`) appear as one observe-only list — not generic shell rows.
- **Chat rich UI.** Same-line `grok-ui` dumps render as callouts, carousels, tabs, and checklists on the Chat run surface, not as JSON.
- **Readable primary actions.** Allow once, Send, and other primary buttons keep the cyan→violet fill and dark ink on hover.
- **Dev engine from source.** `npm run desktop:dev` starts the Dev-channel host from the monorepo and allows the Vite origin.

## Installer

- Asset: `Forge_0.5.0_x64-setup.exe`
- Windows x64, current-user NSIS installer.
- The installer is not Authenticode-signed, so Windows may show an unknown-publisher warning.

## Upgrade

Close Forge before running the installer. Existing per-user conversations and settings are retained by the current-user upgrade path.
Review remains the default. Trusted is saved per workspace. Bypass never persists as an active session mode.
