# Forge 0.6.0 — Stream, chrome, and permission cards that wait

Forge 0.6.0 makes live answers readable while they arrive, ships production desktop chrome, and matches Claude Code / Codex on permission waits.

## Highlights

- **Live answers stay plain text.** Tokens paint in a pre; Markdown and grok-ui layout wait until the run vouches a final answer. No “Building rich layout…” dump of incomplete fences.
- **Bundled Geist and Lucide chrome.** The window no longer depends on Google Fonts. Primary actions, dialogs, and icons use the shipped type and icon set.
- **Desktop update plumbing.** Packaged builds can check GitHub for updates when a signing key is present. WebView crashes go to diagnostics and `forge.log`.
- **Permission cards wait.** Allow stays valid until you Allow, Deny, or cancel the run — no 5-minute silent hang.
- **Always this chat lasts this chat.** Session write/shell grants survive agent-process reclaim and skip the extra Accept-diff step.
- **Trust this folder on the write card.** Saves Trusted workspace for the open folder (including mid-run) so later in-folder text edits auto-apply.

## Verification

- Permission late-Allow, Always-this-chat restore, skip-waitEdit, and Trust-this-folder tests pass.
- Host typecheck, grok-acp typecheck, shell typecheck, and acp-client typecheck pass after the permission change.

## Upgrade

Close Forge before running the installer. Existing per-user conversations and settings are retained by the current-user upgrade path.
Review remains the default. Trusted is saved per workspace. Bypass never persists as an active session mode.
Permission cards no longer expire. Always this chat is remembered for the open Forge window until you change folder.
