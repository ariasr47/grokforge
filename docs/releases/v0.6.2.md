# Forge 0.6.2 — leftover cards, honest session grants, live-end follow

Forge 0.6.2 is the dogfood cut after 0.6.1: cancel no longer leaves a permission card blocking Send, Always this session matches the host grant, the composer locks while the dock owns the turn, and the live end stays at the bottom of a tool burst.

## Highlights

- **Leftover cards settle.** Cancel or a terminal run cancels leftover permission and diff decisions. Send unlocks. Plan review on a finished plan run still waits.
- **Write cancel is a refuse.** Stopping during a write card journals `not_executed`, same as shell.
- **Always this session.** The grant lasts until you change folder and survives engine reclaim. Trust this folder still saves Trusted workspace and allows the current write only.
- **Dock owns the turn.** While a permission, diff, OAuth, or plan card is up, the composer is disabled: *Settle the card below.* Cancel still works.
- **Live-end follow.** If you are already at the bottom, the first tool group no longer jumps the viewport to its header. Thinking and Your turn share the 820px column.
- **Chrome leftovers from 0.6.1.** Palette rows, shell-allowlist switch, Send pill, light sidebar/dock/peek, tooltip stacking, dock height, and focus rings.

## Verification

- Shell typecheck, live-turn / plan-mode / permission-grant / write-cancel tests passed before the 0.6.2 stamp.

## Upgrade

Close Forge before running the installer. Existing per-user conversations and settings are retained by the current-user upgrade path.
Review remains the default. Trusted is saved per workspace. Bypass never persists as an active session mode.
If Check for updates is wired to this release’s `latest.json`, a 0.6.1 install can pick up 0.6.2 from GitHub.
