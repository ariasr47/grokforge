# Forge 0.6.3 — named Chat home and pinned pack

Forge 0.6.3 is the dogfood cut after 0.6.2: in Chat you can name a home on the existing conversation and pin a small pack of files and/or a short note so the next send includes them without paste.

## Highlights

- **Named Chat home.** Commit a durable name on the current Chat conversation. Auto-title is placeholder, not the keep-or-start name.
- **Pinned pack.** Pin up to **5** confined text files and/or a **4,000-character** note. The next Chat send includes that pack without paste.
- **Honest empty and refuse.** No pack invents nothing. A failed pin is not empty. A stale file at send is a materialization fault, not a silent drop.
- **Reload re-checks.** The host re-vouches pinned paths when you open or switch homes. Checking pack is not armed.
- **Code unchanged.** Code still loads `AGENTS.md` then `CLAUDE.md`. Chat pack is not a second recipe file.

## Caps (hard refuse, never silent trim)

- 5 pinned files
- 4,000-character note
- 80,000-character live-read file total at send

## Upgrade

Close Forge before running the installer. Existing per-user conversations and settings are retained by the current-user upgrade path.
Review remains the default. Trusted is saved per workspace. Bypass never persists as an active session mode.
If Check for updates is wired to this release’s `latest.json`, a 0.6.2 install can pick up 0.6.3 from GitHub.
