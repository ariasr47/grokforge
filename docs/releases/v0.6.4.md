# Forge 0.6.4 — PDF text extract

Forge 0.6.4 is the dogfood cut after 0.6.3: attach a text PDF (or `read_file` one) and the turn gets the extracted text. You no longer need a `.txt` export first.

## Highlights

- **PDF attach extracts text.** Chat Attach / drag-drop on a text PDF puts the native text layer in the draft, then on the next send.
- **Agent `read_file` of a PDF.** Chat and Code `read_file` of a confined PDF returns extracted text, or a failed tool — not a silent empty success.
- **Honest failures.** Encrypted, empty-extract (including scanned/image-only), and unreadable stay distinct. No OCR. No PDF viewer.
- **Pack-pin unchanged.** Pinning a PDF as a Chat pack member still refuses.

## Caps

- Source PDF over 20 MiB refuses as unreadable (does not hang).
- Attach emitted text: 80,000 characters (same family as other attach).
- `read_file` emitted text: 100,000 UTF-8 bytes.

## Verification

- PDF-extract quality check passed 19/19. Shell suite 668 pass / 0 fail before the 0.6.4 stamp.

## Upgrade

Close Forge before running the installer. Existing per-user conversations and settings are retained by the current-user upgrade path.
Review remains the default. Trusted is saved per workspace. Bypass never persists as an active session mode.
If Check for updates is wired to this release’s `latest.json`, a 0.6.3 install can pick up 0.6.4 from GitHub.
