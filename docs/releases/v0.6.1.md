# Forge 0.6.1 — Aria chrome, split CSS, signed updater

Forge 0.6.1 packages the stack work after 0.6.0: leftover Settings and run chrome on Aria, Voidglass CSS split by surface, window size that persists, clipboard copy that works in the desktop WebView, and updater signing from the local key file so `latest.json` can ship.

## Highlights

- **Aria chrome.** Settings, messages, diffs, git review, and most leftover `.btn`s use the shipped Button. Command palette is an Aria ComboBox. Sidebar and main are a resizable split.
- **Stores, not one App bag.** Palette / peek / drag live in a chrome store; Always-this-chat flags live in a session-flags store. Run streaming stays on the existing reducer.
- **Voidglass CSS by surface.** Tokens, chrome, run, dock, settings, and short dock/toast enter motion (honors reduced-motion / Calm).
- **Desktop plugins.** Window size and position persist. Copy prefers the Tauri clipboard plugin.
- **Updater signing.** `npm run build:prod` now feeds Tauri `TAURI_SIGNING_PRIVATE_KEY` from `.tauri/updater.key`, so GitHub `latest.json` can be produced.

## Verification

- Shell typecheck, cargo check, Biome on the included set, Vitest unit files, and policy / dock / palette / failure App tests passed before the 0.6.1 stamp.

## Installer

- Asset: `Forge_0.6.1_x64-setup.exe`
- SHA-256: _(filled after the installer build)_
- Windows x64, current-user NSIS installer.
- The installer is not Authenticode-signed, so Windows may show an unknown-publisher warning.

## Upgrade

Close Forge before running the installer. Existing per-user conversations and settings are retained by the current-user upgrade path.
Review remains the default. Trusted is saved per workspace. Bypass never persists as an active session mode.
If Check for updates is wired to this release’s `latest.json`, a 0.6.0 install can pick up 0.6.1 from GitHub.
