# Forge 0.6.5 — Trusted confined deletes and renames

Forge 0.6.5 is the dogfood cut after 0.6.4: in Trusted, a confined single-file delete or rename applies without a permission card and shows on File changes.

## Highlights

- **Trusted auto-apply.** Confined single-file `delete_file` and `rename_file` apply card-free in Trusted, like text edits.
- **File changes.** Deleted and Renamed members show with vouched kind. Deletes/renames do not need a text diff.
- **Review still asks.** The same mutations still card in Review. Deny/cancel does not mint a File changes member.
- **Recovery.** **Restore file** stops if the path exists again. **Revert rename** restores the previous names.
- **Unchanged.** Protected recursive deletes still refuse. Shell `del`/`rm`/`mv` still cards in Trusted and never appears on File changes. Bypass auto-apply still does not mint File changes members.

## Verification

- Trusted-deletes-renames quality check passed 29/29. Shell suite 700 pass / 0 fail before the 0.6.5 stamp.

## Upgrade

Close Forge before running the installer. Existing per-user conversations and settings are retained by the current-user upgrade path.
Review remains the default. Trusted is saved per workspace. Bypass never persists as an active session mode.
If Check for updates is wired to this release’s `latest.json`, a 0.6.4 install can pick up 0.6.5 from GitHub.
