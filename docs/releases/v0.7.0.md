# Forge 0.7.0 — Shareable unsigned (in-repo cut)

Forge 0.7.0 is the 0.7 Shareable cut after 0.6.7: same house grok-acp Code, plus the **install-time SHA pin** so first-run / Settings can show a vouched installer digest. Still unsigned. Not a GitHub release until the operator says `release`.

## Highlights

- **S1 SHA-in-app pin.** NSIS POSTINSTALL runs `write-installer-pin.ps1` (hashed *outside* the payload). Host `GET /api/health.installerSha256` reads `installer-digest.pin` when `version=` matches the app. First-run and Settings already render that voucher.
- **House Code** stays grok-acp. A `grok` CLI on PATH does not divert Code to vendor stdio.
- **Gate honesty** from the 0.6.7→0.7 dogfood tree: in-place Edit command Allow, `apply_patch` hunk-fail quotes, Bypass junction inspection eligibility, vendor Write-title File-changes paths.
- **Unchanged.** Chat is grok-acp. Review is the default. Trusted is saved per workspace. Bypass never persists. Unknown-publisher warning remains (S2 blocked on a cert).
