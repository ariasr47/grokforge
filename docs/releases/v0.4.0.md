# Forge 0.4.0 — Reliable autonomous runs

Forge 0.4.0 makes long-running Grok work reliable, inspectable, and substantially less interruptive while preserving explicit safety boundaries.

## Highlights

- **Grok 4.6 is the inherited default.** New installs and legacy inherited selections migrate to exact `grok-4.6`; supported explicit model choices remain explicit.
- **Three clear permission modes.** Review stays the safe default, Trusted can remember a workspace and auto-apply eligible confined text edits, and advanced Bypass is a visibly dangerous, native-unlocked, session-only capability.
- **No routine read or diff ceremony.** Safe structured reads and fixed inspections do not prompt in Review or Trusted, and accepted edits no longer require a second generic Git-diff confirmation.
- **Durable, honest answers.** Prompt ownership, received answer text, tool activity, decisions, cancellation and terminal state survive disconnects, host restarts and page reloads. Reasoning is never promoted into the answer.
- **Long runs stay alive.** Forge no longer treats elapsed time by itself as a stall. Provider, tool, decision, engine and journal liveness are tracked independently, with recovery and explicit failure only when the relevant boundary supplies evidence.
- **Per-session concurrency.** Each client session owns at most one live run and an isolated ACP generation; separate sessions can work independently without borrowing output or cancellation.
- **Guarded edit recovery.** Trusted auto-edits are journaled and revert only when the current bytes still match the applied edit. Newer user changes are preserved and surfaced as a recovery conflict.
- **Stronger workspace safety.** Structured and fixed-inspection paths use canonical confinement in Review and Trusted, including Windows junction handling and protected-delete circuit breakers. Generic shell and explicit Bypass remain truthfully labeled according to their broader authority.
- **Voidglass by default.** Fresh profiles now consistently open on the locked Voidglass theme with accessible focus, reduced-motion, compact-density and light-theme preferences intact.

## Reliability and verification

- Independent Spire GATE Q: **38/38 acceptance criteria passed**.
- Independent interface conformance: **8/8 probes passed**.
- Final pre-release monorepo baseline before packaging: **455/455 automated tests passed**, plus all TypeScript typechecks, production builds, and 13/13 Rust tests.
- The benchmark records 18 dated observations and 12 scenario comparisons against Codex and Claude Code. Forge matches the scoped flows in 11 comparisons and intentionally trails Codex on safe-default permission friction; it makes no blanket superiority claim.

## Upgrade notes

- Existing explicit supported model choices are preserved. Only inherited or legacy default provenance migrates to `grok-4.6`.
- Review remains the default after upgrade. Trusted is saved per workspace. Bypass never persists as an active session mode and must be unlocked locally on a standard, unmanaged desktop.
- The Windows installer is not code-signed, so Windows may display an unknown-publisher warning.
