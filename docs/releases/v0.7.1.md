# Forge 0.7.1 — PDF extract must not break ACP

Follow-up to 0.7.0. Same unsigned Windows NSIS. PDF extract via `pdfjs-dist` was writing `Warning: Cannot load "@napi-rs/canvas"` onto grok-acp **stdout**. ACP is JSON-RPC on that pipe, so the host showed `Invalid JSON from agent`. Canvas is optional; text-layer extract does not need it.

## Highlights

- **ACP stdout honesty.** Non-JSON agent lines (pdfjs canvas warning) are `agent_log`, not `parse_error`.
- **pdfjs verbosity errors-only** so that warning is less likely to print at all.
- **Unchanged.** House grok-acp Code, SHA pin from 0.7.0, Review default, unknown-publisher warning.

## Verification

- `packages/acp-client/src/client.stdio-noise.test.ts` **1/1**
- `packages/pdf-extract` extract tests **7/7**
