# Reliable Autonomous Runs Behavior Benchmark

## Method and scope

Reviewed 2026-08-15. The closed scenarios compare observable control-flow behavior, not model intelligence, answer quality, price, or an aggregate product ranking. Forge observations come from commands run against the current feature worktree and recorded in the linked builder receipt. Codex and Claude Code observations use current first-party documentation; the locally installed versions (`codex-cli 0.147.0` and Claude Code `2.1.217`) identify the review environment but do not turn documentation into a runtime claim.

`lead` and `trail` are used only where first-party evidence shows a concrete extra blocking operator step or missing outcome. `match` means the products reach the same core outcome under the stated precondition even when their labels or implementation differ. A source that does not define a detail is called out as `not specified`; silence is not scored.
