# Installing Forge

One page. Follow the numbered steps in order. You do not need anything else
installed on your PC first.

## 1. Save the file

Save the installer file you were sent somewhere you can find it, like your
Downloads folder, then double-click it to start.

## 2. If Windows shows a blue warning screen

Windows sometimes shows a screen that says it protected your PC, because
Forge's publisher is shown as unknown. That is expected for this app — it
just hasn't been reviewed by Microsoft yet, not a sign that something is
wrong. If you see that screen, do these two steps in order:

1. Click **More info**.
2. Click **Run anyway**.

**If no warning screen appears at all,** that's fine too — just continue
with step 3 below.

## 3. Finish installing

Follow the on-screen steps to finish installing. When it's done, Forge
opens on its own, or you can open it from the Start menu.

## 4. Sign in

The first time Forge opens, click **Sign in with Grok** and sign in with
your Grok account. Forge remembers this on this PC.

## 5. Start chatting

Type a message and send it. That's it — you're using Forge.

## If something goes wrong

If Forge shows a message saying it couldn't get started, or anything else
looks broken, look for a button called **Save troubleshooting file** on that
screen and click it. Then send the file it saves you, along with a short
note about what you saw, to whoever set Forge up for you.
