The working loop

1

Do a real job

Write a file. Run tests. Plan. Deny. Chat a follow-up. In the running app.

2

Elect one fail

Blocked job first. Then a lie. Then shouty chrome. Never five fixes at once.

3

Smallest fix

If chrome can silently regress, add a test that would have failed before.

4

Recapture

Same job again. Screenshot + json + a one-line log. Then invent a harder job.

We banned rewriting the same probe file over and over. We banned a second host on port 8788. We banned inventing a skills marketplace to “look complete.”

Takeaway. The one product flip: Code stopped being a skin on the Grok terminal.
