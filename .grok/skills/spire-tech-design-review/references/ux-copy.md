# UX copy review

## Labels and instructions

Use the user's vocabulary and a verb that predicts the action. Keep one concept named consistently. Remove jargon, internal state names and instructions that merely compensate for unclear interaction.

Follow the consumer's capitalization convention. When none is declared, use sentence case for interface text; do not impose a universal heading style. Use numerals for counts and second-person recovery guidance when they fit the product voice.

## State copy

- Empty states explain what is absent and the useful next action.
- Loading copy is shown only when delay needs explanation; avoid false precision.
- Success and confirmation copy names what changed and any next step.
- Error copy says what happened, what remains safe and how to recover without exposing internals.
- Destructive confirmation names the object and consequence; prefer undo when recovery is possible.

Preserve user input after recoverable failure. Do not blame the user or claim an action succeeded before it has.

## Tone and terminology

Match the product voice and the seriousness of the moment. Be concise without becoming cryptic. Numerals, dates, units and capitalization follow the existing product convention.

## Localization resilience

Check longer labels, plural forms, reordered phrases, date/number formats and strings assembled from fragments. Do not encode meaning through word order, width or capitalization that only works in one language.

## Evidence

Quote the current copy, explain the user impact and propose exact replacement wording when the data and product decision support it. If the underlying decision is missing, surface that gap rather than inventing copy.
