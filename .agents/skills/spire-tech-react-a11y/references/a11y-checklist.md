# A11y checklist

| Area | Check |
| --- | --- |
| Semantics | heading order, lists, landmarks as needed |
| Keyboard | tab order, Enter/Space activate, Escape closes when expected |
| Focus | visible focus, restore on dialog close |
| Forms | labels, errors linked, required indicated |
| Images | meaningful alt or decorative empty alt |
| Live | polite/assertive only for real updates |
