# Integrity failures

| Failure | Fix |
| --- | --- |
| Label claims "secure" / "verified" without a checkable AC | Drop adjective or add observable criterion |
| Number shown with no field/source | Name source or remove number |
| Tooltip redefines unit (ms as seconds) | Align unit with data |
| Success toast on partial failure | Match copy to actual outcome |
| Empty state says "you're all caught up" when load failed | Distinguish empty vs error |

Defining UX failure mode: **copy that asserts a meaning the data does not support.**
